# Repline

A simple gym log for your phone. Log every set, see your progress, and get a clear target for next time.

**Open the app:** https://swchyd.github.io/repline/

## What it does

- **Workout log**: pick Push, Pull, Legs, Full body or Cardio (or a suggested plan), then log kg × reps for each set.
- **Today's target**: every machine shows what to lift next, based on your last session (add weight only when every set hits the top of the rep range).
- **How-to pictures**: an animated start-to-finish figure and form cues for 60+ exercises, with machine, cable, barbell and dumbbell alternatives.
- **Search by nickname**: find exercises by name, muscle or your own nickname, or add your own.
- **Progress**: charts for every exercise and a weekly check of what's going up, flat or down.
- **Body**: weigh-ins with BMI and waist guideline.
- **Profiles**: switch between people on one phone.
- **Light and dark mode**, phone, tablet and laptop layouts.

## Install it like an app

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Install app (or Add to Home screen)

After the first visit it also works offline.

## Your data

Everything is saved **on your own device** (browser storage). Nothing is uploaded anywhere.
Clearing your browser data deletes your log, so use **History → Machines & backup → Download backup file** now and then. To move to a new phone, download a backup on the old one and use **Load backup file** on the new one.

## Claude features

Reviews and exercise naming open a new chat on [claude.ai](https://claude.ai) with your session already filled in.
Google Calendar planning works only in the Claude-hosted version of Repline.

## Run it yourself

It is a single `index.html` with no build step. Fork the repo and turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
